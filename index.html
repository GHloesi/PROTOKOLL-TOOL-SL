Anleitung – Protokoll-Tool V3.3

1. Protokoll anlegen

Titel, Datum und Ort der Besprechung werden oben eingetragen. Die Angaben erscheinen später im Gesamtprotokoll.

2. Teilnehmer

Teilnehmer können einzeln oder gesammelt eingegeben werden. Mehrere Personen werden durch Komma getrennt.

Beispiel:
Max Mustermann, Müller, Anna Schmidt, Peter

3. Themen und Unterpunkte

Mit „+ Thema“ wird ein Hauptthema angelegt. Innerhalb des Themas können beliebig viele Unterpunkte erzeugt werden. Die Nummerierung erfolgt automatisch.

4. Zuständigkeit

Pro Unterpunkt können mehrere Teilnehmer gleichzeitig ausgewählt werden. Zusätzlich können weitere Personen oder Firmen frei eingetragen werden.

5. Attribute

Zur Verfügung stehen Info, Aufgabe, Entscheidung, Frage, Hinweis und Termin. Zusätzlich können Status und Fälligkeitsdatum gepflegt werden.

6. Audioaufnahme

Mit „Aufnahme starten“ wird eine neue Mikrofonaufnahme begonnen. Nach dem Stoppen kann die Aufnahme zunächst angehört werden.

Neu in V3.3: Die Aufnahme wird nicht automatisch dauerhaft gespeichert. Mit „Aufnahme lokal speichern“ entscheidest du ausdrücklich, ob sie dauerhaft im Browser abgelegt werden soll.

Nach dem lokalen Speichern erscheint der Hinweis „Audio gespeichert“. Beim späteren Laden des Protokolls wird die Aufnahme wieder dem entsprechenden Unterpunkt zugeordnet.

„Gespeichertes Audio löschen“ entfernt die dauerhaft gespeicherte Aufnahme dieses Unterpunktes.

7. Audio-Datei exportieren

Mit „Audio-Datei exportieren“ kann die aktuelle Aufnahme zusätzlich als separate Audiodatei gespeichert werden.

8. Audio → Text

Eine vorhandene Aufnahme kann über die konfigurierte API transkribiert werden. Das Ergebnis erscheint zunächst als Rohtranskription.

9. Live-Diktat

Soweit der Browser dies unterstützt, kann Sprache unmittelbar während des Sprechens in Text umgewandelt werden.

10. Stiftnotiz / Apple Pencil

Jeder Unterpunkt besitzt den Button „✎ Stiftnotiz“. Die Zeichenfläche ist im normalen Protokoll vollständig geschlossen und wird nur beim Antippen dieses Buttons geöffnet.

Die Zeichenfläche kann mit Apple Pencil, Touch oder Maus verwendet werden. Bei unterstützten Geräten werden Pointer-Eingaben einschließlich Stifteingaben verarbeitet.

Die Stiftnotiz eignet sich beispielsweise für Skizzen, handschriftliche Ergänzungen, Pfeile, Maße oder kurze Notizen.

11. Stiftnotiz speichern

Mit „Notiz speichern“ wird die Zeichnung lokal gespeichert und dem aktuellen Unterpunkt zugeordnet. Danach erscheint „Stiftnotiz vorhanden“.

Die Notiz kann später erneut geöffnet und weiterbearbeitet werden.

12. Rückgängig

„↶ Rückgängig“ entfernt den zuletzt ausgeführten Zeichenstrich. Mehrfaches Betätigen geht mehrere Schritte zurück.

13. Zeichenfläche löschen

„Zeichenfläche leeren“ entfernt die Zeichnung zunächst nur aus der aktuellen Zeichenfläche. Erst „Notiz speichern“ übernimmt diesen Zustand.

14. Gespeicherte Stiftnotiz löschen

Mit „Gespeicherte Notiz löschen“ wird die gespeicherte Zeichnung des Unterpunktes aus dem lokalen Speicher entfernt.

15. Protokolltext

Der endgültige Text wird im Feld „Protokolltext“ geführt. Die Rohtranskription bleibt davon getrennt.

16. KI

Über „KI präzisieren“ und „KI zusammenfassen“ kann ein vorhandener Text bearbeitet werden. Ein KI-Ergebnis ersetzt den Protokolltext erst nach ausdrücklichem Übernehmen.

17. Manuelle KI-Hilfe

Ohne direkte Text-API kann ein fertiger Prompt erzeugt werden. Dieser kann in ein anderes KI-System kopiert werden. Die Antwort wird anschließend zurück in das Protokoll übernommen.

18. Gesamtprotokoll

Das tabellarische Gesamtprotokoll enthält Nummer, Inhalt, Attribut, alle Zuständigen, Status und Termin.

19. Lokal speichern

Die normalen Protokolldaten werden im lokalen Browserspeicher abgelegt. Audio und Stiftnotizen werden separat in IndexedDB gespeichert.

20. JSON

Die JSON-Sicherung enthält die strukturierten Protokolldaten, jedoch keine großen Audio- oder Bilddaten.

21. CSV

CSV exportiert die tabellarischen Protokollinformationen. Mehrere Zuständige erscheinen gemeinsam in der Spalte „Zuständig“.

22. PDF

„PDF / Drucken“ öffnet die Druckfunktion des Browsers. Dort kann das Gesamtprotokoll als PDF gespeichert werden.

23. Wichtiger Hinweis zu lokalen Anhängen

Audioaufnahmen und Stiftnotizen liegen lokal im Speicher des verwendeten Browsers und Gerätes. Das Löschen von Browserdaten kann deshalb auch diese gespeicherten Anhänge entfernen. Für wichtige Audioaufnahmen sollte zusätzlich die Funktion „Audio-Datei exportieren“ verwendet werden.
